# ClickHouse Database Documentation Generator

Автоматическое генерирование документации для ClickHouse баз данных в форматах **Markdown** и **HTML**.

## 🎯 Описание

Скрипт подключается к ClickHouse серверу, извлекает информацию о:
- **Таблицах** (структура, размер, количество строк, комментарии)
- **Материализованных представлениях** (запросы, движки)
- **VIEW представлениях** (SQL-определения)

И генерирует красивую документацию с профессиональным дизайном.

## 📋 Требования

- Python 3.8+
- ClickHouse сервер (локальный или удаленный)
- Доступ к системным таблицам ClickHouse

## 🚀 Установка

1. Клонируйте репозиторий:
```bash
git clone <repo-url>
cd click_house_gen_doc
```

2. Установите зависимости:
```bash
pip install -r req.txt
```

## ⚙️ Конфигурация

### Через файл `.env`

Создайте файл `.env` в корне проекта:

```env
CLICKHOUSE_HOST=localhost
CLICKHOUSE_PORT=8123
CLICKHOUSE_USER=default
CLICKHOUSE_PASSWORD=your_password
CLICKHOUSE_DATABASE=your_database
DOC_FORMAT=md
DOC_OUTPUT_DIR=docs

# Ссылка на интерактивную ER-диаграмму (GitLab Pages), необязательно
ER_PAGES_URL=
```

## 📖 Использование

### Генерирование документации в Markdown (по умолчанию)

```bash
python main.py
# или явно
python main.py md
```

Результат:
- `docs/database_schema.md` — главный файл с оглавлением
- `docs/objects/*.md` — таблицы, материализованные представления, VIEW, словари
- `docs/updates.md` — история обновлений версии ClickHouse

### Генерирование документации в HTML

```bash
python main.py html
```

Результат: `docs/database_schema.html`

### Приоритет настроек

1. **Аргумент командной строки**: `md` или `html`
2. **Переменная окружения**: `DOC_FORMAT`
3. **По умолчанию**: `md`

## 🕸️ ER-диаграмма

Скрипт `er_diagram.py` строит ER-диаграмму базы данных: подключается к ClickHouse,
собирает таблицы и колонки, восстанавливает связи между таблицами по именам
FK-колонок (`*_id`, `*_uuid`) и генерирует диаграмму.

```bash
python er_diagram.py
```

Результат:
- `docs/er_diagram.md` — Mermaid-диаграмма (рендерится нативно в GitLab/GitHub)
- `docs/er_diagram.html` — интерактивная версия (зум, панорама, поиск, подсветка связей по клику)

> В ClickHouse нет внешних ключей, поэтому связи восстанавливаются эвристически
> по именам колонок и могут быть неполными/неточными.

## ❓ FAQ

Скрипт `faq.py` генерирует интерактивную HTML-страницу с часто задаваемыми
вопросами из файла `faq.txt`.

```bash
python faq.py
```

Результат: `faq.html` (аккордеон + поиск по вопросам).

Формат `faq.txt`:

```text
Q: Вопрос?
A: Ответ (может быть многострочным).
```

- `Q:` — начало вопроса;
- `A:` — ответ (маркер необязателен, всё до следующего `Q:` считается ответом).
